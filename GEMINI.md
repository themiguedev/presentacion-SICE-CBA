# Reglas del Proyecto: Presentación SICE-CBA

## Sincronización Automática con el Repositorio de GitHub (Obligatorio)

1. **Auto-commit y Push Automático**:
   - Cada vez que se realice cualquier modificación, edición, adición o corrección en los archivos de este proyecto (`index.html`, `README.md`, assets o cualquier otro), es **OBLIGATORIO** preparar los cambios (`git add`), realizar un commit descriptivo y subirlos inmediatamente al repositorio remoto con `git push origin main`.
   
2. **Confirmación**:
   - Tras ejecutar el push, verificar que el árbol de trabajo quede limpio y confirmar al usuario el hash o estado del commit subido a GitHub (`https://github.com/themiguedev/presentacion-SICE-CBA`).
